# PetCare 360 — Challenge 2026 | Sprint 4

## Compliance, Quality Assurance & Tests

### Sobre o projeto

O **PetCare 360** é uma solução voltada ao acompanhamento da saúde e do bem-estar de animais de estimação, integrando funcionalidades de monitoramento, gerenciamento de pets, consultas veterinárias e acompanhamento de indicadores de saúde.

Nesta quarta Sprint do Challenge FIAP 2026, o foco da disciplina de **Compliance, Quality Assurance & Tests** foi o planejamento de testes manuais e a automação de testes funcionais.

## Parte A — Testes Manuais

Os testes manuais foram planejados e documentados no **Azure DevOps Boards**, contemplando as principais funcionalidades do PetCare 360.

Foram definidos **9 casos de teste**, incluindo cenários positivos e negativos, com:

- Objetivo do teste;
- Pré-condições;
- Dados de entrada (Input);
- Resultados esperados (Output);
- Procedimentos de execução;
- Vinculação aos itens do backlog.

## Parte B — Testes Automatizados

A automação dos testes funcionais foi realizada utilizando a ferramenta **Scandium**, por meio de gravação e reprodução de interações com a interface web do PetCare 360.

A aplicação utilizada nos testes foi desenvolvida em **Java com Thymeleaf** e disponibilizada na plataforma Render.

### Ferramentas utilizadas

- Azure DevOps Boards — planejamento dos testes manuais;
- Scandium — automação dos testes funcionais;
- GitHub — versionamento e entrega;
- Render — hospedagem da aplicação Java;
- Java e Thymeleaf — desenvolvimento da aplicação web.
